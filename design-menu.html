📌 Phase별 핵심 변경 요약
Phase 1 — 인프라·인증
기반 메뉴 구성
  • 홈 (랜딩 + 가입 유도)
  • 전쟁터 (열람 전용, 비로그인 가능)
  • 아지트 (로그인 + 진영 배정 후)
  • 로그인 / 회원가입 버튼
  • 프로필 드롭다운 (설정, 로그아웃)
  • 관리자 메뉴 (기본형)
Phase 2 — 커뮤니티 핵심
드롭다운 + 티커 추가
  • 실시간 점수 티커 (GNB 상단 고정)
  • 아지트 드롭다운 (게시판 목록)
  • 전쟁터 드롭다운 (5개 게시판)
  • 통계 메뉴 (일별 점수)
  • 알림 🔔 (뱃지 카운트)
  • 프로필 확장 (내 게시물·댓글)
Phase 3 — 분석·실시간
완성형 메뉴
  • 통계 드롭다운 (일·월·연·리포트)
  • 실시간 투표 독립 메뉴
  • 프로필 확장 (매너점수·칭호)
  • WebSocket 실시간 알림
  • 관리자 드롭다운 완성형
  • 실시간 모니터 패널
